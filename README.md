# Minder beta

Downloads and the update feed for the Minder closed beta.

Get the latest build under [Releases](https://github.com/vanabbe/minder-releases/releases).
Minder updates itself after that.

The app's source lives elsewhere; this repository only holds signed, notarized builds and
`appcast.xml`, the feed Minder checks for new versions.
